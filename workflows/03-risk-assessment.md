# 风险评估工作流

对新能源项目进行六类风险评估与商务风险（合作方）评估。

## 风险评估框架

### 六类风险分类

| 风险类别 | 评估内容 | 权重 |
|----------|----------|------|
| 市场风险 | 竞争格局、电价波动、消纳能力 | 25% |
| 技术风险 | 设备可靠性、技术成熟度、并网技术 | 20% |
| 政策风险 | 补贴政策、并网政策、土地政策 | 25% |
| 现金流风险 | 收入稳定性、成本可控性、资金来源 | 15% |
| 建设风险 | 工期延误、成本超支、施工质量 | 10% |
| 商务风险 | 合作方信用、合同条款、利益分配 | 25% |

### 评分标准

每类风险按 1-5 分评估：

| 评分 | 等级 | 说明 |
|------|------|------|
| 1 | 极低 | 几乎没有风险 |
| 2 | 低 | 风险可控，有预案 |
| 3 | 中 | 存在一定风险，需关注 |
| 4 | 高 | 风险较大，需重点关注 |
| 5 | 极高 | 风险不可接受 |

### 综合评级

| 综合得分 | 风险等级 | 建议 |
|-----------|----------|------|
| 1.0-1.9 | 低 | 可正常参与 |
| 2.0-2.9 | 中 | 参与但需关注风险 |
| 3.0-3.9 | 高 | 谨慎参与，强化风控 |
| 4.0-5.0 | 极高 | 建议不参与或重新谈判 |

## 各风险类别详细评估

### 1. 市场风险

| 评估项 | 评估要点 | 评分 |
|--------|----------|------|
| 竞争格局 | 区域内同类项目数量、竞争态势 | 1-5 |
| 电价波动 | 保障性收购 vs 市场化交易、价格波动历史 | 1-5 |
| 消纳能力 | 电网消纳空间、弃风弃光率 | 1-5 |
| 上网电价 | 脱硫煤电价、竞价/平价项目 | 1-5 |

### 2. 技术风险

| 评估项 | 评估要点 | 评分 |
|--------|----------|------|
| 设备可靠性 | 品牌、质量、故障率、保修期 | 1-5 |
| 技术成熟度 | 新技术 vs 成熟技术、转化效率 | 1-5 |
| 并网技术 | 接入方案、升压站配置、特高压 | 1-5 |
| 运维能力 | 运维团队、备件供应、远程监控 | 1-5 |

### 3. 政策风险

| 评估项 | 评估要点 | 评分 |
|--------|----------|------|
| 补贴政策 | 补贴强度、发放及时性、拖欠风险 | 1-5 |
| 并网政策 | 并网期限、消纳保障、电价保障 | 1-5 |
| 土地政策 | 土地获取难度、用地性质、租赁期限 | 1-5 |
| 政策稳定性 | 行业政策历史稳定性、近期变化 | 1-5 |

### 4. 现金流风险

| 评估项 | 评估要点 | 评分 |
|--------|----------|------|
| 收入稳定性 | 电量收购比例、电费结算周期 | 1-5 |
| 成本可控性 | 运维成本波动、备件价格 | 1-5 |
| 资金来源 | 资本金到位、贷款承诺函 | 1-5 |
| 现金流覆盖 | DSCR覆盖情况、流动性储备 | 1-5 |

### 5. 建设风险

| 评估项 | 评估要点 | 评分 |
|--------|----------|------|
| 工期延误 | 历史项目工期、冬季施工影响 | 1-5 |
| 成本超支 | 单位造价控制、历史超支率 | 1-5 |
| 施工质量 | 施工单位资质、历史质量记录 | 1-5 |
| 安全事故 | 历史安全事故、安全管理体系 | 1-5 |

### 6. 商务风险（合作方风险）

| 评估项 | 评估要点 | 评分 |
|--------|----------|------|
| 合作方信用 | 征信报告、司法记录、历史合作 | 1-5 |
| 资信水平 | 财务状况、负债率、现金流 | 1-5 |
| 配合度 | 沟通效率、决策速度、履约意愿 | 1-5 |
| 利益冲突 | 关联关系、同业竞争、股权交叉 | 1-5 |
