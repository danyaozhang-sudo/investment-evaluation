# 合作方尽职调查工作流

对项目合作方进行多维度评估，支持多合作方和GP专属评估。

## 评估范围

### 合作方类型

| 类型 | 评估重点 | 优先级 |
|------|----------|--------|
| 控股方/主要股东 | 资信、背景、配合度 | 高 |
| 联合投资方 | 出资能力、历史合作 | 高 |
| EPC承包商 | 施工资质、工程业绩、成本控制 | 中 |
| 运营商 | 运维能力、历史表现 | 中 |
| 设备供应商 | 设备质量、售后服务 | 中 |
| 金融机构 | 贷款条件、资金到位 | 中 |

## 评估框架（5维度）

### 1. 信誉口碑

| 评估项 | 数据来源 | 评分 |
|--------|----------|------|
| 工商信息 | 国家企业信用信息公示系统 | 1-5 |
| 法律诉讼 | 企查查/天眼查裁判文书 | 1-5 |
| 行政处罚 | 官方公示平台 | 1-5 |
| 行业声誉 | 业内口碑、同行评价 | 1-5 |

### 2. 资信水平

| 评估项 | 数据来源 | 评分 |
|--------|----------|------|
| 财务报表 | 审计报告（近2年） | 1-5 |
| 资产负债率 | 财务报表计算 | 1-5 |
| 现金流状况 | 经营现金流净额 | 1-5 |
| 银行授信 | 银行授信额度/已用额度 | 1-5 |

### 3. 合作实力

| 评估项 | 数据来源 | 评分 |
|--------|----------|------|
| 历史业绩 | 已完成项目案例 | 1-5 |
| 市场份额 | 行业排名、市场地位 | 1-5 |
| 资源整合能力 | 资金、技术、人才储备 | 1-5 |
| 团队稳定性 | 核心团队留存率 | 1-5 |

### 4. 配合度

| 评估项 | 评估要点 | 评分 |
|--------|----------|------|
| 沟通效率 | 响应速度、信息透明度 | 1-5 |
| 决策速度 | 内部审批流程 | 1-5 |
| 履约意愿 | 历史合同履约情况 | 1-5 |
| 冲突解决 | 争议处理方式 | 1-5 |

### 5. 关联关系/利益冲突

| 评估项 | 评估要点 | 评分 |
|--------|----------|------|
| 股权交叉 | 与其他合作方的股权关系 | 1-5 |
| 同业竞争 | 是否存在同业竞争关系 | 1-5 |
| 关联交易 | 历史关联交易情况 | 1-5 |
|利益输送风险 | 定价公允性、交易合理性 | 1-5 |

## GP角色专属评估

担任基金GP时需额外评估以下内容：

### 控制权架构

| 评估项 | 说明 |
|--------|------|
| 投委会席位 | GP获得席位数量 |
| 一票否决权 | 是否有针对特定事项的一票否决权 |
| 表决机制 | 多数决 vs 共识决 |
| 信息权 | 财务数据获取频率和详细程度 |
| 退出权 | GP能否独立决定退出时机 |

### Carry分配结构

| 评估项 | 说明 |
|--------|------|
| 门槛收益率 | LP收回投资+优先收益的门槛（通常8%） |
| Catch-up | 达到门槛后GP追回Carry的比例 |
| Carry比例 | GP享受的超额收益比例（通常20%） |
| 分配顺序 | 本金→优先收益→超额部分→Carry |

### 管理费结构

| 评估项 | 说明 |
|--------|------|
| 管理费率 | 通常2%/年 |
| 计提基数 | 实缴出资 vs 认缴出资 |
| 计提期间 | 投资期 vs 整个存续期 |
| 覆盖范围 | 仅覆盖GP运营成本 vs 包含人员工资 |

### 投委会席位影响

```
## 投委会影响评估

### 席位配置
- GP席位：X席
- LP席位：X席
- 其他席位：X席

### 决策事项
- 需一致同意：投资决策、退出决策、关联担保
- 需多数同意：追加投资、项目公司重大事项

### 影响评估
| 决策类型 | GP影响力 | 说明 |
|-----------|----------|------|
| 投资决策 | 强/中/弱 | ... |
| 退出决策 | 强/中/弱 | ... |
| 日常管理 | 强/中/弱 | ... |

### 风险提示
- 一票否决权范围过宽可能影响决策效率
- 席位不足可能导致被动接受不利条款
```

## 多合作方协调

当项目涉及多个合作方时，评估各方利益一致性：

### 利益一致性分析

| 合作方 | 核心诉求 | 与我方契合度 | 潜在冲突 |
|--------|----------|--------------|----------|
| 控股方 | 控制权、长期收益 | 高/中/低 | ... |
| 其他投资方 | 财务回报、退出时机 | 高/中/低 | ... |
| EPC承包商 | 工程利润、施工进度 | 高/中/低 | ... |
| ... | ... | ... | ... |

### 协调机制

- 股东协议中的表决机制
- 争议解决条款
- 优先购买权/随售权条款

## 输出格式

```
## 合作方尽职调查报告

### 合作方概览
| 合作方 | 角色 | 综合评分 | 风险等级 |
|--------|------|----------|----------|
| 合作方A | 控股方 | X.X/5 | 低/中/高 |
| 合作方B | 联合投资方 | X.X/5 | 低/中/高 |

### 合作方A详细评估

- 资信水平：X.X/5（说明）
- 合作实力：X.X/5（说明）
- 配合度：X.X/5（说明）
- 利益冲突：X.X/5（说明）

### GP角色专属评估（若适用）

- Carry分配：...
- 管理费结构：...

- 是否参与该合作方主导的项目：是/否/需谈判
- 风险缓释建议：...
```

## 使用模板

使用 `templates/partner-assessment-template.md` 填写评分。

## 注意事项

- 评分需有客观依据，避免主观臆断
- 对于上市公司，可参考公开披露信息
- 对于非上市公司，需通过多种渠道核实
- 利益冲突评估需特别关注股权交叉和关联交易
