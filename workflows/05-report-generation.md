# 报告生成工作流

生成完整的新能源项目投资评估报告（Word文档）。

## 报告生成流程

### Step 1: 确认数据完整性

在生成报告前，确认以下数据已收集：

- [ ] 项目参数表（Phase 1产出）
- [ ] 财务模型结果（Phase 2产出）
- [ ] 风险评估矩阵（Phase 3产出）
- [ ] 合作方尽调报告（Phase 3产出）
- [ ] 敏感性分析（Phase 5产出）

### Step 2: 选择报告模板

使用 `templates/report-template.md` 作为报告结构模板。

### Step 3: 生成Word文档

使用 `minimax-docx` skill 生成Word文档：

1. 调用 `minimax-docx` skill
2. 按模板结构填充内容
3. 插入表格和图表
4. 生成最终文档

### Step 4: 校验与输出

- 校验各章节内容完整性
- 检查表格数据一致性
- 确认综合建议清晰明确
- 输出最终报告

## 报告结构（7章节）

### 第1章：执行摘要

**内容要求**
- 项目概述（名称、类型、规模、地点）
- 核心结论（一句话说明是否建议参与）
- 关键指标摘要（IRR、NPV、DSCR、风险等级）
- 主要风险提示（1-3条）
- 参与建议（方式、规模、条件）

**字数**：300-500字

### 第2章：项目基本情况

**内容要求**
- 项目概况（背景、建设内容、进度）
- 技术方案（设备选型、技术路线）
- 区位条件（资源情况、接入条件）
- 审批进展（核准、备案、并网等）
- 合作方介绍（主要股东及背景）

**格式**：文字+表格+位置图

### 第3章：财务评估

**内容要求**

#### 3.1 股权直投模式
- 财务假设（电价、发电量、运维成本、建设投资）
- 全投资IRR、资本金IRR
- NPV（WACC折现）
- DSCR
- LCOE（风电/光伏项目）
- 回收期（静态+动态）

#### 3.2 股权基金GP+基石投资人模式（如适用）
- 基金结构（规模、管理费、Carry）
- 基金IRR、GP实得IRR
- 投委会席位及影响

#### 3.3 EPC模式（如适用）
- EPC合同金额、实际成本
- EPC利润、工程利润率
- 与股权收益对比

**格式**：表格为主，配文字说明

### 第4章：风险评估矩阵

**内容要求**
- 六类风险评分表（市场/技术/政策/现金流/建设/商务）
- 风险热力图
- 重点风险提示
- 风险缓解建议

**格式**：表格+文字

### 第5章：合作方尽职调查

**内容要求**
- 各合作方评估（信誉/资信/实力/配合度/利益冲突）
- GP专属评估（如适用）
- 多方利益一致性分析
- 综合建议

**格式**：表格+文字

### 第6章：综合建议

**内容要求**
- 是否参与建议（强烈推荐/推荐/中性/不推荐）
- 参与方式建议（单选/多选）
- 参与条件建议（如有）
- 风险提示
- 后续行动建议

### 第7章：敏感性分析

**内容要求**
- 关键参数敏感性（电价/发电量/建设成本/利率）
- 乐观/基准/悲观三种情景对比
- 建议关注的风险点

**格式**：表格+图表

## 报告输出格式

- 文件名：`{项目名称}_投资评估报告_{日期}.docx`
- 路径：`projects/{project-name}/report.docx`
- 语言：中文
- 格式：标准Word格式，含目录、页眉页脚

## 注意事项

- 各章节引用数据需标注来源
- 表格应有表头和单位
- 结论应有明确数据支撑，避免模糊表述
- 风险提示需具体，不可泛泛而谈
- 综合建议需明确，不可模棱两可
