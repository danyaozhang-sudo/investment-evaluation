# 财务建模工作流

对新能源项目进行三种参与模式的财务建模。

## 模式一：股权直投

### 财务指标计算

**全投资IRR**
- 公式：使NPV=0的折现率
- 现金流：每年现金净流入（含折旧回收、利息支付前）
- 参考：`references/financial-formulas.md`

**资本金IRR**
- 公式：资本金投入为基数，计算股东现金流IRR
- 现金流：收入 - 运维成本 - 利息支出 - 税金 + 折旧抵税 + 残值

**NPV（净现值）**
- 公式：∑ (CFt / (1+WACC)^t)
- WACC取值：行业基准8-10%，根据风险调整
- 参考：`references/financial-formulas.md`

**DSCR（偿债覆盖率）**
- 公式：可用于偿还债务的现金流 / 当期应还本息
- 最低要求：≥1.2x
- 参考：`references/financial-formulas.md`

**LCOE（平准化度电成本）**
- 公式：总投资现值 / 发电量现值 + 运维成本现值 / 发电量现值
- 单位：元/kWh
- 参考：`references/financial-formulas.md`

**回收期**
- 静态：累计净现金流转正年份
- 动态：使累计折现现金流转正年份（含折现）
- 参考：`references/financial-formulas.md`

### 输出格式

```
## 股权直投模式财务评估

### 核心指标
| 指标 | 数值 | 基准对比 |
|------|------|----------|
| 全投资IRR | X% | 行业基准8-12% |
| 资本金IRR | X% | 行业基准8-12% |
| NPV | X万元 | >0为正 |
| DSCR | X.xx倍 | 最低1.2x |
| LCOE | X.xx元/kWh | 行业基准 |
| 静态回收期 | X年 | 行业8-12年 |
| 动态回收期 | X年 | 含折现 |

### 财务模型假设
- 折现率(WACC)：X%
- 运营期：X年
- 资本金比例：X%
- 贷款利率：X%
```

## 模式二：股权基金GP+基石投资人

### 基金结构参数

| 参数 | 说明 |
|------|------|
| 基金规模 | X万元 |
| 管理费 | 2%/年（通常按实缴出资计算） |
| Carry | 超额收益20%（通常先返还本金+优先收益8%） |
| 投资期 | 3-5年 |
| 运营期 | 10-15年 |

### 基金IRR计算

**管理费影响**
- 管理费 = 实缴出资 × 2% × 年数
- 每年从基金资产中扣除

**Carry计算**
- 门槛收益率：通常8%/年
- 超额部分：GP享受20%

**基金层面IRR**
- 现金流：LP出资、GP出资、管理费支出、项目分红、退出
- 考虑 Carry 分配后的实际回报

### 投委会席位影响

- 席位数量影响决策权
- 一票否决权需特别关注
- 评估对估值的影响

### 输出格式

```
## 股权基金GP+基石投资人模式财务评估

### 基金结构
| 参数 | 数值 |
|------|------|
| 基金规模 | X万元 |
| 管理费率 | X%/年 |
| Carry比例 | X% |
| 门槛收益率 | X% |
| 投资期 | X年 |
| 运营期 | X年 |

### 核心指标
| 指标 | 数值 |
|------|------|
| 基金IRR | X% |
| GP实得IRR | X%（扣Carry后） |
| 基石投资人IRR | X%（扣Carry后） |

### 投委会影响评估
- 席位数量：X席
- 一票否决权：是/否
- 影响评估：正面/中性/负面
```

## 模式三：EPC参与

### EPC利润计算

**收入端**
- EPC合同金额 = 单位kW造价 × 装机容量
- 或：商务谈判确定的合同总价

**成本端**
- 实际施工成本（设备+人工+材料+管理）
- 利润率 = (合同金额 - 实际成本) / 合同金额

### 参考
- `references/epc-modeling.md`

### 输出格式

```
## EPC模式财务评估

### EPC参数
| 参数 | 数值 |
|------|------|
| 装机容量 | X MW |
| 单位kW造价 | X元/kW |
| EPC合同金额 | X万元 |
| 实际施工成本 | X万元 |
| EPC利润 | X万元 |
| 工程利润率 | X% |

### 盈利分析
- 与股权收益对比
- 风险调整后收益评估
```

## 注意事项

- 所有计算需使用正确的现金流时序
- 贷款利率采用实际利率（如LPR+溢价）
- 折旧采用直线法或加速折旧（看当地政策）
- 残值处理：通常为总投资×3-5%
- 税金：增值税、所得税（看项目公司情况）
