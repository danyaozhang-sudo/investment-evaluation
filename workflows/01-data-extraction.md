# 数据解析工作流

从用户提供的材料中提取项目关键参数。

## 输入材料类型

### 文字材料（商业计划书/可研报告）
直接粘贴文本内容，系统自动识别以下信息：

**项目基本信息**
- 项目名称、项目地址、建设规模
- 项目类型（风电/光伏/储能/算力中心）
- 建设工期、运营期
- 土地/选址情况

**技术参数**
- 装机容量（MW）
- 发电量（年发电小时数/首年发电量）
- 设备清单（风机/组件型号）
- 技术方案

**财务假设**
- 电价（元/kWh）
- 运维成本（万元/年）
- 建设投资（万元）
- 资本金比例
- 贷款利率、贷款年限

### Excel财务模型
使用 `minimax-xlsx` skill 读取：

**必读Sheet**
- `财务假设`或`参数表`：总投资、发电量、电价、运维成本
- `折旧表`：折旧年限、折旧方法
- `借款还本付息表`：利率、还款方式

**提取步骤**
1. 调用 `minimax-xlsx` 读取文件
2. 定位关键参数区域
3. 提取并校验数值
4. 填写参数表

## 输出

`projects/{project-name}/parameters.md`

## 数据质量检查

- [ ] 关键参数完整（总投资、发电量、电价、运维成本、利率）
- [ ] 单位一致（万元/MW/元/kWh）
- [ ] 数值合理（参考 `references/industry-benchmarks.md`）
- [ ] 数据来源标注清晰
- [ ] 置信度评级（高/中/低）

## 置信度评级说明

- **高**：数据来自正式Excel模型或可研报告，有明确数值
- **中**：数据来自文字描述，需要估算
- **低**：数据缺失，需要用户补充
