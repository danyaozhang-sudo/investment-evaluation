# 敏感性分析工作流

对新能源项目进行关键参数敏感性和情景分析。

## 敏感性分析范围

### 关键参数识别

| 参数 | 变化范围 | 优先级 | 说明 |
|------|----------|--------|------|
| 上网电价 | ±10%/±20% | 高 | 影响最大 |
| 年发电量 | ±10%/±20% | 高 | 受资源/设备影响 |
| 建设成本 | ±10%/±20% | 中 | 影响总投资 |
| 贷款利率 | ±50bp/±100bp | 中 | 影响财务费用 |
| 运维成本 | ±10%/±20% | 低 | 占比较低 |
| 资本金比例 | ±5% | 低 | 影响杠杆效应 |

## 敏感性分析方法

### 单因素敏感性分析

对每个关键参数单独变化±10%和±20%，观察对IRR的影响：

```
## {参数名称}敏感性分析

| 变化幅度 | {参数}值 | 全投资IRR | 资本金IRR | NPV |
|----------|----------|-----------|-----------|-----|
| -20% | X | X% | X% | X万元 |
| -10% | X | X% | X% | X万元 |
| 基准 | X | X% | X% | X万元 |
| +10% | X | X% | X% | X万元 |
| +20% | X | X% | X% | X万元 |

### 敏感性排名
1. {参数A}：IRR变化 X% / ±10%
2. {参数B}：IRR变化 X% / ±10%
3. ...
```

### 双因素敏感性分析（可选）

对于电价和发电量的组合分析：

| 电价/发电量 | -20% | -10% | 基准 | +10% | +20% |
|-------------|------|------|------|------|------|
| -20% | IRR_X% | IRR_X% | IRR_X% | IRR_X% | IRR_X% |
| -10% | IRR_X% | IRR_X% | IRR_X% | IRR_X% | IRR_X% |
| 基准 | IRR_X% | IRR_X% | IRR_X% | IRR_X% | IRR_X% |
| +10% | IRR_X% | IRR_X% | IRR_X% | IRR_X% | IRR_X% |
| +20% | IRR_X% | IRR_X% | IRR_X% | IRR_X% | IRR_X% |

## 情景分析

### 三种情景定义

| 情景 | 条件 | 电价 | 发电量 | 成本 |
|------|------|------|--------|------|
| 乐观 | 资源好、电价高、成本低 | +10% | +10% | -5% |
| 基准 | 最可能情况 | 基准 | 基准 | 基准 |
| 悲观 | 资源差、电价低、成本高 | -10% | -10% | +10% |

### 情景对比表

```
## 情景分析对比

| 指标 | 乐观情景 | 基准情景 | 悲观情景 |
|------|----------|----------|----------|
| 电价（元/kWh） | X | X | X |
| 年发电量（万kWh） | X | X | X |
| 建设成本（万元） | X | X | X |
| 全投资IRR | X% | X% | X% |
| 资本金IRR | X% | X% | X% |
| NPV（万元） | X | X | X |
| 回收期（年） | X | X | X |

### 情景分析结论
- 乐观情景下IRR达到X%，具有较好投资价值
- 悲观情景下IRR为X%，仍能满足最低回报要求/无法满足最低回报要求
- 项目抗风险能力：强/中/弱
```

## 盈亏平衡分析

### 电价盈亏平衡

使资本金IRR等于基准收益率（8%）的最低电价：

```
## 盈亏平衡分析

### 电价盈亏平衡点
- 最低保障电价：X元/kWh
- 当前电价：X元/kWh
- 安全边际：X%

### 发电量盈亏平衡点
- 最低年发电小时数：X小时
- 预测年发电小时数：X小时
- 安全边际：X%

### 建设成本盈亏平衡点
- 最高单位造价：X元/kW
- 实际单位造价：X元/kW
- 安全边际：X%
```

4. 利率敏感性

2. 情景分析结论

### 三、盈亏平衡分析

3. 建设成本盈亏平衡点

### 四、综合结论

## 注意事项

- 敏感性分析应基于合理的参数变化范围
- 情景设置应结合行业基准和项目实际情况
- 结论应明确，不可模糊表述
- 盈亏平衡分析对投资决策有重要参考价值
